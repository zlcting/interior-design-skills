# 白模光影交付标准

适用于用户选定 white-minimal 的新网页、独立 HTML 或 Home3D 表现任务。默认采用 `white-home3d-v1`；历史项目保留原版本，其他风格不套用。先按既有流程确认家具精细度和风格；明确选择沿用。光影标准不会把基础家具自动变为精细家具。

## 权威预设与适配

参数唯一来源为 [white-render-profile.json](white-render-profile.json)。锁定预设 ID、版本和 SHA-256，把最终派生参数随包保存。预设来自已确认的 Home3D 白模表现方向：适度的主/补光、柔和接触阴影、明确的局部暖光、通透玻璃与正交构图。

`white_render_profile.py` 按本项目房间边界计算灯光目标、阴影范围及相机，支持平移和负坐标；代表房间默认取最大沙发所在房间，也可用 `visualization.focus_room_id` 或 `--room` 明确指定。没有可识别代表房间时先使用全屋并记录缺口，不照抄案例相机、不挪动家具来凑构图。局部灯只来自解析方案中实际存在的发光附加物，不为满足效果新增灯具；正式灯位须另有设计来源。

实时与离线各自使用校准后的参数。实时采用此预设；Cycles 保留选定风格的 AgX、工作室灯及正式渲染质量。两者的曝光数值和光强单位不能直接照搬。现有白模 v4 的正式离线默认 2400px/128采样保留，过程小样可降低并明确标记。不要把实时像素倍率、阴影或采样无限加大来代替光照设计。

## 可执行交付流程

先从锁定模型生成精细几何并通过交换校核，再运行本工具建立网页表现：

```sh
python3 scripts/prepare_white_viewer.py /path/to/project \
  --glb /path/to/project/visuals/interior.glb \
  --out /path/to/project/visuals/white-web-v1 \
  --plan /path/to/resolved-plan.json \
  --room R01
```

命令在总控 skill 目录内执行；目录外使用脚本绝对路径。`--plan` 可省略，由当前家具库解析；已有同源解析计划时优先传入，工具检查房间和家具占地一致。`--room` 可省略；`--blender` 可指定已安装 Blender 路径。输出目录必须为空，旧版保留。

工具输出 `打开精细白模.html`、`white-web.glb`、`white-render-config.json`、`white-web-validation.json`、`white-viewer-manifest.json`。HTML 完整内嵌引擎、模型和配置，无 Node/CDN 依赖。源模型、GLB和相机数据不回写。

`bake_white_web.py` 将接触 AO 写入 COLOR_0，使模型进入网页后仍有接触层次；只烘焙遮蔽，不把可开关灯光的照明烘死。先恢复原始单色 PBR 因子再替换顶点 AO，重复生成不累计变黑；玻璃不参与遮蔽实体。输出逐对象重新导入验证，几何点位容差 0.02mm 不代表测绘精度。

当前烘焙器已限定为无纹理、唯一材质名、OPAQUE PBR及透射玻璃；不支持的输入明确报错，不能静默丢纹理、alpha或替换材质。需要其他材质时先扩展并验证工具。

Home3D 或自定义页面优先消费同一个配置及 `assets/white-viewer/studio.js`，通过 `WhiteStudio.create(THREE, renderer, scene, config)` 建立光照；不要在页面再维护一套散落的光强、色调和阴影常量。自定义页面提供的 THREE API 须与绑定运行版本兼容；独立入口已包含验证过的 Three.js r171。该接口只负责表现，不增加设备模拟控制。

## 视觉放行

程序通过只能记为参数/资源或几何通过，`visual_review` 初始为 `not_reviewed`，不可自动升级。

- 保留全屋与代表房间截图，使用同一画布、投影、相机、日间环境及灯状态比较；全屋缩略图不与客厅近景直接比较精细度。
- 放大沙发曲面、滚边、支脚及柜体边缘，检查白色层次、AO脏黑、过曝、接触阴影和玻璃；模型缺精细家具时单独记录。
- 局部灯以同机位开/关图检查灯罩发光与附近照明，环境曝光保持不变；没有局部灯时记不适用，不能调整全局曝光冒充设备开关。
- 检查桌面与窄屏的代表空间构图、控件可达性、明显锯齿和运行稳定性。按设备能力降级须记录实际参数与差异，不能仍宣称完全一致。
- 记录 `visual_review` 的实际观察与截图。独立 HTML 的 file:// 与 HTTP 测试分开；工具禁止文件协议时不绕过，不以 HTTP 通过补写直开通过。

出现明显过曝、发灰、接触丢失、玻璃遮挡或构图裁切时，定位材质、AO、灯光或相机原因再复核。更改权威预设参数需新版本；只改户型派生坐标不会更改预设版本。当前已交付包保持原状，未经授权不批量重写。
