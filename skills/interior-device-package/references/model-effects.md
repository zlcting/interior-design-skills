# 形态与效果

按需查scope.json的modelTypeId、templateKey和effectGroup。首批29种设备43项形态：36固定、6程序化帘类、1灯带路径。灯包括吸顶、落地、筒灯、灯带、轨道灯；吊灯属于后续，已有Demo不计首批。

| 共享组 | 标定与目标表现 |
|---|---|
| surface | 发光面位置/法向/范围；250ms明暗过渡，不加呼吸光；真面光及动态色温需扩展 |
| point | 发光面与点光分别绑定，250ms过渡；已有基线为固定暖色开关/亮度 |
| directional | 每个灯头位置/方向/角度、整体控制；250ms过渡，不加装饰光柱 |
| path | 保留路径/截面/转角和连续发光面；250ms过渡，预编译几何不等于路径照明实现 |
| airflow | 出风口位置/方向/范围，确认真实运行后400ms渐入/出；不以power猜运行 |
| robot-dock | 机身/基座分节点；离座移出800ms+淡出600ms，确认回座后渐显600ms+归位800ms |
| curtain | 单/双开、布/纱、窗洞参数；当前开度300ms插值，布纱两层分别控制 |
| roller | 顶部卷收基准/帘面/方向；当前开度300ms插值 |
| blind | 升降/叶片/转轴；开度300ms、角度250ms且独立，基础通道尚不支持旋转 |
| lift | 固定顶机/双杆/轴/行程；按当前高度300ms插值 |
| running | 本体不动、小提示锚点；运行2400ms周期，完成一次800ms，需要可信运行反馈 |

此表是需求目标，不是首版工具实现清单。参数写进source文件不表示已经执行；工具范围见package-contract.md。

空调确认实际运行后才按实际模式显示冷蓝/暖橙/中性气流，设定制冷不出冷风，除湿显示文字。风扇/净化器不做叶片、摇头机械动画；无雾加湿器用running，不喷雾。机器人基座固定，外出/暂停/回充仍隐藏机身，确认回座才归位；不显示路径，不补播历史或重复反馈。可合成一个保留子节点的GLB；独立基座身份需产品确认。

传感器、面板、插座、电视、锁、冰箱、净饮机正常静态，点击看真实信息，不自造视频、门扇开合或面板负载状态。门窗磁铁成对标定，不冒充跨宿主联动。燃气报警器首批吸顶，洗衣机首批滚筒且不转内筒。
